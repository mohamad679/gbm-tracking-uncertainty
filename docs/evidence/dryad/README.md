# Dryad external-transfer evidence

This directory contains the **current frozen evidence** for the three-experiment Dryad technical-transfer arm. The reader-facing scientific interpretation is [`../../dryad-confirmatory-final-report.md`](../../dryad-confirmatory-final-report.md).

- `dryad-confirmatory-local-resumption-protocol.json` — frozen local-resumption protocol.
- `dryad-confirmatory-schema-lock.json` — pre-outcome committed mapping for the three tumour-cell experiments.
- `dryad-confirmatory-local-runbook.md` — local acquisition, verification, normalization, and one-time evaluation procedure.
- `dryad-confirmatory-result.json.gz` — deterministic gzip of the one-time machine-readable result.

Raw Dryad deposits and normalized generated CSVs are intentionally not committed. Moving these evidence files into this directory does not change their contents or scientific status.
