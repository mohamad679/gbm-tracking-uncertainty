# راهنمای کوتاه بازبینی مسیر سلول‌ها برای متخصص

این ابزار یک وب‌سایت عمومی نیست؛ یک صفحه آفلاین (`results/stage1-viewer/index.html`) است که تصاویر نمونه در رایانه بازبین کنار آن نگهداری می‌شوند. داده از دو موش و دو بازه ده‌فریمی از هر موش آمده است. تصاویرِ خام در GitHub قرار ندارند. هدف، آزمودن امکان دنبال کردن هویت یک سلول در فریم‌های متوالی است؛ نه تأیید یک نتیجه زیستی یا بررسی اثر دارو.

## معنی بخش‌های صفحه

| مورد | کار بازبین |
| --- | --- |
| Reviewer ID | یک شناسه مستعار برای شخص بازبین؛ در تمام ثبت‌های او یکسان باشد. |
| Window | یکی از چهار بازه ثابت؛ `early` آغاز و `late` انتهای همان ROI است. هر بازه ۱۰ فریم دارد. |
| Channel: Tumor / Vessel | تصویر سلول‌های نشاندار / کانال مجاور رگ. ثبت مرکز سلول روی کانال Tumor انجام شود. |
| Frame، Previous، Next | جابه‌جایی بین فریم‌ها؛ شمارش فریم از صفر شروع می‌شود. |
| Local cell ID | نام دلخواه یک سلول در همان بازه، مثلاً `cell_1`. تنها وقتی واقعاً هویت همان سلول را تشخیص می‌دهید، این شناسه را در فریم بعد هم تکرار کنید. |
| کلیک روی تصویر | ثبت مرکز تقریبی سلول؛ مختصات `x/y` در تصویر ۵۰۱×۵۰۱ اصلی صادر می‌شوند. |
| Difficulty | `Easy` برای سلول جدا و روشن؛ `Hard / crowded` برای سلول مبهم، ضعیف یا مجاور دیگران. |
| Identity decision | `Uncertain link` یعنی اتصال هویتی به فریم قبل قابل اطمینان نیست؛ در این حالت دلیل را در `Reason` مشخص کنید. |
| Reason | `low_signal` سیگنال ضعیف؛ `overlap` هم‌پوشانی؛ `edge` نزدیکی مرز/برش؛ `other` سایر. |
| Mark occluded / Mark left view | سلولی که محلش دیده نمی‌شود / از ناحیه قابل مشاهده خارج شده؛ مختصات جعلی برای آن ننویسید. |
| Undo last row | فقط آخرین ثبت را برمی‌گرداند، نه لزوماً آخرین ثبت همان فریم. |
| Download my CSV | پروندهٔ ثبت‌های بازبین را روی رایانه ذخیره می‌کند. **قبل از بستن یا تازه‌سازی صفحه دانلود کنید**؛ صفحه ذخیره خودکار ندارد. |

## کار مورد انتظار از یک متخصص

ابتدا چهار بازه را فقط از روی تصاویر، **بدون دیدن خروجی الگوریتم**، دنبال کنید؛ در هر بازه چند سلول روشن و چند مورد دشوار را ثبت کنید. در هر فریم، شناسه، مرکز تقریبی، مبهم بودن پیوند و موارد خروج از کادر را ثبت کنید. فایل CSV مستقل خودتان را نگه دارید. سپس مسیرهای پیشنهادی ماشین را جداگانه با تصاویر مقایسه کنید و برای هر اختلافِ مهم بنویسید آیا سلول اشتباه تشخیص داده شده، شناسه عوض شده، یا تصویر اساساً مبهم است. شناسه‌ها در دو فایل لزوماً هم‌نام نیستند؛ تطبیق باید از روی تصویر انجام شود.

مسیرهای ماشین صرفاً پیشنهاد هستند و ممکن است در ناحیه هم‌پوشانی یا مرز تصویر غلط باشند. نتیجه یک بازبین انسانی که بعداً پیشنهادها را بازبینی کرده، «بازبینی انسانیِ پیشنهاد ماشین» است، نه توافق بین دو بازبین مستقل. اگر فقط یک متخصص در دسترس باشد، مقدار توافق بین‌ارزیاب و معیار عبور قبلی مرحله ۱ قابل گزارش نیست؛ نتیجه برای پایلوت مقدماتی استفاده شود و برچسب **REVISE** باقی بماند.

واحد زمانی و اندازه فیزیکی پیکسل هنوز تأیید نشده‌اند. نمونه‌های فعلی هر دو تیمارشده‌اند؛ بررسی اثر تیمار از آن‌ها ممکن نیست. تصاویر و CSVها بدون روشن شدن حق بازنشر داده عمومی نشوند.
